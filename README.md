# VOIDNET // Ghost Console

A fictional, browser-only cyberpunk command center. All network activity and terminal output are simulated; it does not access real systems.

Open `index.html` directly in a browser. Use the sidebar to switch between Overview, Console, Network, Intel, Vault, and Settings.

The Console supports `help`, `ls`, `whoami`, `scan`, `trace`, `status`, `access`, `clear`, and `reboot`.
