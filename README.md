# fake-hacker-console

A retro terminal-inspired fake hacker console built with plain HTML, CSS, and JavaScript.

## Run it locally

Open `index.html` in a browser.

## Features

- green-on-black CRT aesthetic
- fake boot sequence
- interactive terminal commands
- responsive layout
- no dependencies

## Commands included

- `help`
- `ls`
- `whoami`
- `pwd`
- `scan`
- `access`
- `cat`
- `reboot`
- `clear`
- `exit`
